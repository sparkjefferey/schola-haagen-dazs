# 每周一题 · 运营小抄

> 轻运营、零代码、零花费。用网站现成的「谕令」+「论坛」就能跑起来。
> 目标：给成员一个**每周必回来看一眼**的理由，把空馆子填热。

---

## 一、机制怎么转

1. 掌门（你）每周在**燕京阁 → 谕令**发一条置顶命题，全馆顶部可见。
2. 同时在**论坛 → 冷食哲学**开一个对应首帖，把人"接住"。
3. 成员去论坛接话、辩论。
4. 月末掌门择善者，在学榜/论文库里点名表彰（现有功能够用）。

谕令负责"喊人"，论坛帖负责"接住讨论"。两者配套才成立。

---

## 二、本期定稿文案（开馆第一题）

### ① 谕令（燕京阁 → 谕令 → 新建，勾选「置顶」）

**标题：**
```
每周一题·开馆第一题
```

**内容：**
```
谕：本学派自今日起，立「每周一题」之制。

每七日，掌门于谕令颁一命题，诸生赴论坛开辩，各陈所见。月末汇其善者，录入学榜，以为学派积薪。

首题——「冷食，是否算得上一门正经学问？」
或曰：冰淇淋不过甜腻之物，何足登大雅之堂？或曰：一勺之中，有物性、有记忆、有文明，岂可轻之？

诸生可赴论坛「冷食哲学」版，各抒己见。此谕。
```

### ② 论坛首帖（论坛 → 发新帖，分类选「冷食哲学」）

**标题：**
```
每周一题·其一｜冷食是否算得上一门正经学问？
```

**正文：**
```
掌门既颁首题，吾且抛砖引玉。

所谓"正经学问"，衡之以三问：

其一，可究其理否？——奶脂何以成晶、冷香何以驻口、甜觉何以动人的物理与感官机制，难道不算学问？

其二，可载其史否？——一勺冰淇淋，半部近代消费史与殖民贸易史，美食人类学早有专论。

其三，可立其法否？——若学派真要立一部《冰淇淋宪章》，其第一条当写"甘甜须诚，不可欺舌"，抑或"冷食者，自由之味也"？

愿闻诸君高见：冷食，究竟是消遣，还是被低估的学问？
（本帖为「每周一题」常驻题眼，诸生可随时接续。）
```

---

## 三、发布步骤（照做即可）

1. 用管理员账号登录。
2. **发谕令**：燕京阁 → 谕令 → 新建谕令，粘上面的标题与内容，**勾选「置顶」**，保存。
3. **发论坛帖**：论坛 → 发新帖，标题/正文如上，分类选 **冷食哲学**，发布。
4. **（可选）拉人**：燕京阁 → 徽章司，铸一个「一次有效」的 R- 码，备注写"赠予某某"，发给信得过的朋友，对方注册填码即入派。

---

## 四、后续换题模板

每周换一题，复制下面改 `N` 和命题即可：

**谕令标题：** `每周一题·其N`
**论坛帖标题：** `每周一题·其N｜【这里写新命题】`
**论坛分类：** 按命题性质选（哲学类→冷食哲学；读书类→经典导读；事务类→学派事务；闲扯→闲话长廊）

命题储备（随手取用）：
- 「甜，究竟是感官的妥协，还是理性的奖赏？」
- 「若学派要立一部《冰淇淋宪章》，第一条该写什么？」
- 「冷藏，是保存，还是对时间的挑衅？」
- 「什么是本学派最该守住的一条底线？」

---

## 五、配套提醒（不做也行，但做了更热）

- 俩创始人本周各认领一块：一人投 1 篇论文，一人开 2 个论题帖。
- 内容密度才是活跃度的地基，空馆子再花哨也没人逛。
