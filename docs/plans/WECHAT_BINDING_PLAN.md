## 一、大白话版（先看懂这个）

1. **要在网站上用微信登录，必须走微信官方提供的「网站应用」登录通道**（业内叫 OAuth 扫码登录）。
2. 流程就是：网页弹个二维码 → 你拿手机微信扫一下 → 微信确认 → 网站就知道"是你" → 自动登录或把微信和你的账号绑在一起。
3. **有两道硬性门槛不在代码里**：
   - 得去「微信开放平台」开个账号并交 **300 元认证费**（腾讯收，一次性，免不掉）。
   - 得有一个**真实域名**（你目前还没买），并且要走 https（不能带 `:3000` 端口）。
4. 代码本身不难，大约 1–2 天能写完测完，因为咱们已经有现成的"登录/会话/cookie"体系可以复用。

---

## 二、技术选型：为什么用「微信开放平台 · 网站应用」

微信生态里有好几种登录，对应不同产品，别选错：

| 方式 | 适用场景 | 对我们合不合适 |
|---|---|---|
| **开放平台·网站应用（OAuth）** | 独立网站，用户扫码登录 | ✅ 最合适，本次选用 |
| 公众号·服务号网页授权 | 只能在微信 App 内打开的网页 | ❌ 我们网站是独立站，用户不一定在微信里打开 |
| 小程序 | 另起一个小程序产品 | ❌ 成本更高，没必要 |

选定：**微信开放平台 网站应用 OAuth2.0（scope = snsapi_login）**。

- 扫码后微信回传给我们的，是用户在「本网站应用」下的唯一身份证：**openid**（一串稳定字符串）。
- 跨多个微信产品（公众号+网站+小程序）才需要 **unionid**，我们单应用用不到，先不碰。

## 三、前置资质（你来做，我帮写代码）

### 第 1 步：微信开放平台认证（约 300 元）
1. 打开 https://open.weixin.qq.com ，注册开放平台账号。
2. 做「开发者资质认证」，交 300 元（腾讯收，一次性）。个人/企业都能认证。
3. 在「网站应用」里新建一个应用，填：
   - 应用名称（如"沙藏学馆"）
   - **授权回调域名**（填你买的域名，例如 `xueguan.xyz`，**不要带 http/端口**）
4. 等审核（通常 1–3 个工作日）。
5. 审核通过后拿到两个东西：**AppID** 和 **AppSecret**（AppSecret 像密码，必须藏好）。

### 第 2 步：买域名 + 配 https（与之前"买帅气域名"是同一步）
- 域名去买好（候选 `academos.xyz` / `peripatos.xyz` / `shazang.xyz` / `xueguan.xyz`）。
- DNS 指向咱们 DMIT 香港服务器，配 https 证书（可用 Caddy 自动签，或 Cloudflare 免费证书）。
- 回调地址必须是 `https://你的域名/...`，不能带 `:3000`。

> 说明：DMIT 香港服务器**技术上免备案也能跑微信 OAuth**（微信只要求回调域名网络可达，香港 IP 微信能访问）。但微信审核时可能建议域名备案，稳妥起见建议备案；这点以你实际申请时的提示为准，我不在文档里打包票。

## 四、数据库改动（一行迁移，老库不破坏）

在 `lib/db.ts` 现有的「轻量迁移」区域加一列（复用咱们已有的 `addCol` 机制，自动补列、幂等安全）：

```ts
addCol("users", "wechat_openid", "wechat_openid TEXT UNIQUE");
```

可选（展示用）：`wechat_nickname`、`wechat_avatar`，让用户页显示微信昵称/头像。

## 五、后端代码改动清单

| 文件 | 改什么 |
|---|---|
| `lib/db.ts` | 迁移区加 `wechat_openid` 列（见上） |
| `lib/auth.ts` | 新增 `getUserByWechat(openid)`、`loginByWechat(openid)`——查用户、复用现有 `createSession` 发会话 cookie |
| `app/api/auth/wechat/route.ts`（新建） | 生成 `state`（防 CSRF），拼微信授权 URL，重定向过去；支持 `?mode=login` / `?mode=bind` |
| `app/api/auth/wechat/callback/route.ts`（新建） | 收 `code` + 校验 `state` → 服务端用 code+AppSecret 换 openid → 按模式决定「绑定当前账号」或「直接登录」 |
| `.env` / `.env.example` | 加 `WECHAT_APPID`、`WECHAT_APPSECRET`、`WECHAT_REDIRECT_URI` |
| `docker-compose.yml` | 注入上述环境变量（与现有 `SCHOLAR_CORE_KEY` 同一写法） |

**安全要点：**
- AppSecret 只在服务端用，绝不进前端、绝不进 git 仓库。
- `state` 参数防跨站伪造，存在短期 cookie 或会话里。
- openid 当唯一键；绑定前先确认当前登录用户身份（bind 模式必须已登录）。

## 七、扫码登录/绑定时序（文字版）

```
用户点按钮
  → 我们重定向到微信（带 state + AppID + 回调地址）
  → 微信出二维码
  → 用户手机微信扫码并确认
  → 微信回跳我们的 callback，带 code
  → 我们服务端用 code 换 openid（带 AppSecret，这一步用户看不到）
  → 已登录 = 把 openid 写进当前账号（绑定）
  → 未登录且有绑定 = 直接发会话 cookie 登录
  → 未登录且无绑定 = 引导注册/绑定
  → 进首页
```

- 如果网站只是咱俩小圈子用：手动账号已够，**这 300 元 + 域名可能不值**。
