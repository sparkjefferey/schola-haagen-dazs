# 开通系统邮件提醒 · 大白话指南

> 用途：点亮网站「弱口令双通道提醒」里的真·邮件（站内「讯息」系统消息已经上线，真邮件只差 SMTP 凭据）。
> 性质：账号开通、授权码获取由你在网页操作；填进服务器 `.env` 那一步可由助手代劳（已授权「自己解决」）。

## 〇、先说结论
**推荐用 QQ 邮箱 SMTP**：零成本、免域名、不用验证域名、能直接发到任意邮箱。
（之前考虑的 Resend 要买域名验证，不如 QQ 省事；故改为 QQ 优先。）

## 一、QQ 邮箱 SMTP 参数（填到 `.env`）
| 项目 | 值 |
|---|---|
| SMTP Host | `smtp.qq.com` |
| 端口 | `465`（SSL/TLS，推荐）或 `587`（STARTTLS） |
| 用户名 | **你的完整 QQ 邮箱**，如 `123456@qq.com` |
| 密码 | **授权码**（16 位，不是 QQ 登录密码！） |
| 发件人(From) | 必须 = 上面的 QQ 邮箱本身 |

## 二、开通步骤（你来做，约 3 分钟）
1. 登录电脑版 **mail.qq.com**（或设置页）。
2. 右上角「设置」→「账户」→ 找到 **POP3/IMAP/SMTP** 那一栏，点 **开启 POP3/SMTP 服务**。
3. QQ 会让你用手机发短信验证，验证后**生成一串 16 位授权码**（形如 `abcdwxyzefghijkl`）。**立刻复制保存**，页面关了就看不到，只能重新生成。
4. 记下两样东西：
   - 你的 QQ 邮箱全名（如 `123456@qq.com`）
   - 那串 16 位授权码

## 三、填进网站（二选一）
拿到「邮箱 + 授权码」后：

- **图方便**：把 `邮箱` 和 `授权码` 发我，我 SSH 写进服务器 `/opt/schola-haagen-dazs/.env`（以下四项）并重启容器，几分钟点亮。
  ```
  SMTP_HOST=smtp.qq.com
  SMTP_PORT=465
  SMTP_USER=你的QQ邮箱@qq.com
  SMTP_PASS=16位授权码
  SMTP_FROM=你的QQ邮箱@qq.com
  ```
- **想学习**：自己进服务器 `nano /opt/schola-haagen-dazs/.env` 填好，再 `docker compose up -d`。

> `.env` 模板 `.env.example` 已更新为 QQ 优先说明，变量名完全一致。

## 四、常见坑
- **密码不是 QQ 登录密码**，是「授权码」。填登录密码会报认证失败。
- **From 必须等于该 QQ 邮箱**，不能写成别的域名（如 noreply@schola.com），否则被拒。
- 个人 QQ 邮箱发信有频率限制（每天几十到一百封量级），对「弱口令低频提醒」完全够用；但若将来做大规模群发会触顶。
- 发到 Gmail 等可能进「垃圾箱」，提醒用户「加白名单」即可。
- 授权码泄露等同于邮箱发信权：怀疑泄露就在 QQ 设置里「关闭再开启」重新生成，旧码作废。

## 五、备选方案（仍可用）
- **Resend**（https://resend.com）：免费 3000/月，但**必须验证自有域名**（需花钱买域名）。适合将来要专业发信、独立域名时。
- **Gmail**：host=smtp.gmail.com，密码用「应用专用密码」，同样需开启两步验证后才能生成。

## 六、安全
- 凭据写入 `.env`，已在 gitignore，不会进仓库。
- 当前 `lib/email.ts` 已用 `busy_timeout` + 升级 nodemailer v9（防头部注入），收件人是用户输入也能扛。
- 拿到凭据后建议先让用户自助改一次弱口令测试一封，确认收到再全量放开。
